HOW IT WORKS / طریقہ کار

Simple steps from job to payment.

کام تلاش کرنے سے لے کر کام مکمل کرنے تک Daily Rozgar کا آسان workflow۔

FOR WORKERS / کارکنوں کے لیے

Find work and get started

کارکن کے لیے آسان step-by-step process۔

01 — Create Account Daily Rozgar پر اپنا account بنائیں۔
02 — Complete Profile اپنی skills اور ضروری معلومات شامل کریں۔
03 — Find a Job اپنی مہارت کے مطابق available jobs دیکھیں۔
04 — Apply مناسب job کے لیے application بھیجیں۔
05 — Get Selected Employer کی طرف سے selection کا انتظار کریں۔
06 — Complete Work کام مکمل کریں اور completion process مکمل کریں۔
FOR EMPLOYERS / آجرین کے لیے

Post a job and find a worker

Employer کے لیے آسان step-by-step process۔

01 — Post a Job Job title، description، category، location اور pay شامل کریں۔
02 — Receive Applications اپنی job پر آنے والی worker applications دیکھیں۔
03 — Select a Worker مناسب worker کو job کے لیے select کریں۔
04 — Start Work Accepted worker کے ساتھ کام شروع کریں۔
05 — Complete Work کام مکمل ہونے کے بعد completion record کریں۔
06 — Payment Agreed payment process مکمل کریں اور record برقرار رکھیں۔
THE WORKFLOW

One connected process

ایک ہی platform پر job، application اور work progress کو manage کرنے کا مقصد۔

Job Posted → Application → Selection → Work Started → Work Completed

Daily Rozgar کا مقصد workers اور employers کے درمیان روزانہ اور short-term work کے لیے ایک واضح workflow فراہم کرنا ہے۔

Job پوسٹ ہونے کے بعد workers apply کر سکتے ہیں، employer مناسب worker select کر سکتا ہے، اور accepted work کو start اور complete کیا جا سکتا ہے۔

SAFETY & TRUST

Keep every step clear

کام شروع کرنے سے پہلے ضروری معلومات واضح رکھیں۔

Clear Job Details Job، location، duration اور pay کی معلومات دیکھیں۔
Confirm Selection کام شروع کرنے سے پہلے worker اور employer دونوں selection واضح رکھیں۔
Record Work Status Work started اور completed status platform کے workflow میں record کریں۔
